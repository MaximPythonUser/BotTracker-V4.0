# 🏋️ Training Tracker Bot

Умный Telegram‑бот для отслеживания разовых тренировок: добавляет, редактирует, удаляет, присылает напоминания и спрашивает о результате.

**Статус:** Production Ready (готово к деплою)  
**Язык:** Python 3.9+  
**Автор:** Максим  

> «Бот, который не ошибается» — это не слоган, а архитектура: каждое действие пользователя синхронизировано с базой данных и планировщиком задач. Если тренировка удалена — исчезают и напоминания. Если время изменено — старая задача удаляется, создаётся новая. Никаких рассинхронов.

## ✨ Ключевые преимущества

- **Гибридный ввод и FSM.** Дата выбирается через Inline‑календарь (русская локализация), название и время — пошаговым вводом. Для редактирования достаточно нажать кнопку — не нужно помнить ID или вводить сложные команды.
- **Защита от ошибок.** Жёсткая валидация формата даты и времени. Бот не сохранит некорректные данные и вежливо подскажет, как исправить.
- **Автоматическая синхронизация.** Удаление тренировки удаляет соответствующие задачи из APScheduler. Редактирование времени — удаляет старое напоминание и создаёт новое.
- **Восстановление расписания.** При перезапуске бота все активные напоминания автоматически восстанавливаются из БД.
- **Персонализация.** Приветствие по имени пользователя (`first_name`) из профиля Telegram.
- **Асинхронность.** `aiosqlite` и `aiogram 3.x` исключают блокировку event loop даже при высокой нагрузке.

## 📋 Функционал

- `/add` — добавить тренировку через пошаговый диалог с календарём.
- `/my_trainings` — список своих тренировок с нумерацией.
- `/edit` — выбрать тренировку и отредактировать дату (календарь), название или время.
- `/delete <номер>` — удалить тренировку по номеру из списка.
- **Inline‑кнопки после тренировки:** через час после начала бот присылает кнопки:
  - ✅ «Прошла» — тренировка отмечается как завершённая и удаляется.
  - 🗑 «Удалить» — просто удалить запись.
  - 🔄 «Перенести» — пока реализовано как рекомендация создать новую тренировку (автоматический перенос в планах).

## 🧠 Архитектура и решения

| Проблема | Решение в проекте |
| --- | --- |
| Рассинхрон БД и планировщика | При удалении/редактировании задачи APScheduler удаляются программно по ID `reminder_*` и `check_*`. |
| Потеря задач при рестарте | `schedule_existing_reminders()` восстанавливает все активные задачи из БД при старте. |
| Дублирование напоминаний | При редактировании времени старое напоминание удаляется, создаётся новое. |
| Блокировка потока | `aiosqlite` обеспечивает неблокирующий доступ к SQLite. |
| Ошибки формата даты | Дата выбирается в Inline‑календаре (`aiogram_calendar`), время валидируется регулярным форматом `HH:MM`. |

## 🛠 Технологии

- **aiogram 3.x** — асинхронный фреймворк для Telegram‑ботов.
- **APScheduler + SQLAlchemyJobStore** — планировщик задач с сохранением расписания в SQLite.
- **aiosqlite** — асинхронная работа с SQLite.
- **FSM (Finite State Machine)** — пошаговые диалоги.
- **pytz** — корректная работа с часовыми поясами (`Europe/Moscow`).
- **python-dotenv** — безопасное хранение токена в `.env`.
- **aiogram_calendar** — календарь с русской локалью.

## 🗃 Структура данных

Таблица `one_off_trainings`:

- `id` — уникальный идентификатор (используется для ID задач в планировщике).
- `user_id` — владелец тренировки (масштабирование на множество пользователей).
- `date`, `start_time` — дата и время (отдельно для удобного редактирования).
- `training_name` — название тренировки.
- `status` — статус: `pending`, `done`, `missed`.
